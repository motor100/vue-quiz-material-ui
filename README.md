# VueJS Quiz Bach Flower
#### КВИЗ анкета подбор БАДов Цветы Баха для https://naturapharma.ru


## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```

#### Node v24.18.0

##### Инструкция по парсингу данных из Excel в файле src/services/excelParser.js

###### NPM пакет xlsx подключается локально из папки src/xlsx. Удаленный репозиторий без VPN не работает.
